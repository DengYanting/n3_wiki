# N3 文法示範句型

> 這是起始整理，不是 JLPT 官方完整文法清單。候選句型參考民間學習資源；接續與解說依日語用法整理，例句由本 Wiki 自行撰寫。

## ～として

- **接續**：名詞 + として
- **意思**：以……身分／資格；作為……
- **用法**：說明人物或事物擔任的角色、資格或立場。
- **例句**：彼女は通訳として会議に参加しました。
- **翻譯**：她以口譯員的身分參加了會議。
- **來源**：[文法候選來源](../sources/yatta-n3-grammar-candidates.md)

## ～にとって

- **接續**：名詞 + にとって
- **意思**：對……而言
- **用法**：從某人或某群體的立場評價事物。
- **例句**：この辞書は日本語を勉強する人にとって便利です。
- **翻譯**：這本字典對學日文的人來說很方便。
- **來源**：[文法候選來源](../sources/yatta-n3-grammar-candidates.md)

## ～たびに

- **接續**：動詞辭書形 + たびに；名詞 + の + たびに
- **意思**：每當……就……
- **用法**：表示某件事每次發生時，另一件事也隨之發生。
- **例句**：この歌を聞くたびに、初めて日本へ行った時を思い出します。
- **翻譯**：每次聽到這首歌，我就會想起第一次去日本的時候。
- **來源**：[文法候選來源](../sources/yatta-n3-grammar-candidates.md)

## ～一方で

- **接續**：普通形 + 一方で；な形容詞／名詞 + である一方で
- **意思**：另一方面；同時也……
- **用法**：呈現兩個不同面向，或對照同一主題的兩種情況。
- **例句**：この町は便利な一方で、家賃が高いです。
- **翻譯**：這個城鎮很方便，但另一方面租金也很高。
- **來源**：[文法候選來源](../sources/yatta-n3-grammar-candidates.md)


## ～によって

- **接續**：名詞 + によって
- **意思**：依……而不同；根據……
- **用法**：指出情況會因對象或條件而異。
- **例句**：国によって、食事の習慣が違います。
- **翻譯**：各國的飲食習慣都不一樣。
- **來源**：[文法候選來源](../sources/yatta-n3-grammar-candidates.md)

## ところが

- **接續**：句首連接詞
- **意思**：然而；沒想到
- **用法**：引出與前文預期不同的結果。
- **例句**：早く出発しました。ところが、電車が遅れて到着も遅くなりました。
- **翻譯**：我很早就出發了。沒想到電車誤點，結果還是晚到了。
- **來源**：[文法候選來源](../sources/yatta-n3-grammar-candidates.md)

## ～おかげで

- **接續**：名詞 + の + おかげで；普通形 + おかげで
- **意思**：多虧……；托……的福
- **用法**：表示帶來正面結果的原因。
- **例句**：先生のおかげで、作文が完成しました。
- **翻譯**：多虧老師，我完成了作文。
- **來源**：[文法候選來源](../sources/yatta-n3-grammar-candidates.md)

## ～せいで

- **接續**：名詞 + の + せいで；普通形 + せいで
- **意思**：都怪……；因為……（負面結果）
- **用法**：指出造成不理想結果的原因。
- **例句**：雨のせいで、試合が中止になりました。
- **翻譯**：因為下雨，比賽取消了。
- **來源**：[文法候選來源](../sources/yatta-n3-grammar-candidates.md)

## ～たとたん（に）

- **接續**：動詞た形 + とたん（に）
- **意思**：剛一……就……
- **用法**：表示前項一發生，後項就立刻發生，常帶有意外感。
- **例句**：ドアを開けたとたん、猫が飛び出しました。
- **翻譯**：門一打開，貓就衝了出來。
- **來源**：[文法候選來源](../sources/yatta-n3-grammar-candidates.md)

## ～ば～ほど

- **接續**：動詞ば形 + 動詞辭書形 + ほど
- **意思**：越……越……
- **用法**：表示前項程度增加時，後項程度也隨之增加。
- **例句**：練習すればするほど、発音が自然になります。
- **翻譯**：越練習，發音就會越自然。
- **來源**：[文法候選來源](../sources/yatta-n3-grammar-candidates.md)

## ～ようとする

- **接續**：動詞意向形 + とする
- **意思**：試圖……；正要……
- **用法**：依上下文表示嘗試做某事，或正要開始做某事。
- **例句**：出かけようとした時、電話が鳴りました。
- **翻譯**：正要出門時，電話響了。
- **來源**：[文法候選來源](../sources/yatta-n3-grammar-candidates.md)

## ～がち

- **接續**：動詞ます形去ます + がち；名詞 + がち
- **意思**：容易……；常常……
- **用法**：表示某種情況容易發生，常用於負面或不理想的傾向。
- **例句**：忙しいと、昼食を抜きがちです。
- **翻譯**：一忙起來就容易不吃午餐。
- **來源**：[文法候選來源](../sources/yatta-n3-grammar-candidates.md)

## ～ざるを得ない

- **接續**：動詞ない形去ない + ざるを得ない（する → せざるを得ない）
- **意思**：不得不……；只好……
- **用法**：表示雖不情願，但受情況所迫必須採取行動。
- **例句**：電車が止まったので、駅で待たざるを得ませんでした。
- **翻譯**：因為電車停駛，我只好在車站等。
- **來源**：[文法候選來源](../sources/yatta-n3-grammar-candidates.md)

## ～ばかりでなく

- **接續**：名詞 + ばかりでなく；普通形 + ばかりでなく
- **意思**：不只……；不僅……而且……
- **用法**：補充另一個同樣成立的內容，後句常接「も」。
- **例句**：彼は日本語ばかりでなく、韓国語も話せます。
- **翻譯**：他不只會說日文，也會說韓文。
- **來源**：[文法候選來源](../sources/yatta-n3-grammar-candidates.md)
